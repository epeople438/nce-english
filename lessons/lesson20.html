第1关 · 练习课 · this / that / these / those + 形容词

1逐句点击，听发音！

🔑 本课语法重点：指示代词

this / that → 指一个（单数）
these / those → 指多个（复数）
this / these → 近处（这/这些）
that / those → 远处（那/那些）

Those children are tired. → Their mother is tired, too.
